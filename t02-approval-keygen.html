T02 核准金鑰產生器

離線執行，不連網、不存檔、不上傳。關掉這一頁，金鑰就從記憶體消失。

先看這三條，再看下面的按鈕

  1. 這一頁只能在手機／平板／另一台電腦開。在 Mac 上開，頁面會自己鎖住不給按，因為在那台機器產生的金鑰，等於沒有解決「產出者也讀得到」的問題。
  2. 私鑰只貼進 GitHub 的 secret 欄位，不要貼給任何人（包括我）。貼完就按最下面的「清空畫面」。
  3. 你只需要把公鑰（或上面那串指紋）給我。公鑰外流沒有關係，私鑰外流等於整條核准鏈作廢。

做完回我一句「建好了」，再把指紋貼給我。剩下的我全自動。

如果這一頁開不起來（例如手機只給你看文字）

改用任何一台別台電腦的終端機，兩行貼上就跑完：

openssl ecparam -genkey -name prime256v1 -noout -out t02-approval-key.pem
openssl ec -in t02-approval-key.pem -pubout -out t02-approval-pub.pem

私鑰在 t02-approval-key.pem（貼進 GitHub secret 後刪掉），公鑰在 t02-approval-pub.pem（貼給我）。兩行都要在同一台機器、同一個資料夾跑。
